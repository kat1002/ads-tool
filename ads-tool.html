Ads Tool

Làm theo 4 bước: chọn file → thêm link store → kiểm tra variant → xử lý và tải về.

Xem thay đổi
  1. Giải nén file zip vừa tải, đè lên thư mục Ads Tool cũ.
  2. Mở chrome://extensions (Edge: edge://extensions).
  3. Bấm Reload ở Ads Tool.

1 Chọn file nguồn

File playable gốc (.zip hoặc .html). Chọn nhiều file thì mỗi file được nhân với từng variant.

Kéo thả file vào đây hoặc bấm để chọn
Chưa chọn file.

2 Thêm link store

Nhập link Google Play và/hoặc App Store của app. Tool tự lấy tên app và icon 512×512. Cần thêm nhiều app: bấm “Thêm” rồi dán cả danh sách.

Bấm “Thêm” → dán danh sách link → “Tiếp theo” → kiểm tra tên/icon → “Xác nhận”. Mỗi app sẽ thành một variant ở bước 3.

3 Kiểm tra variant

Mỗi variant sẽ tạo ra một file output. Bấm “Chỉnh sửa” trên variant để đổi tên, link hoặc icon.

Chưa có variant. Làm bước 2 để thêm từ link store, hoặc bấm “Thêm variant trống” để nhập tay.

Để trống “Tên output” thì file được đặt tên {tên nguồn}_{tên app}.zip. Có thể dùng {base} {app} {index} {next} {ext}.

4 Tuỳ chọn xử lý

Mặc định là đủ dùng, chỉ đổi khi cần.

Chưa có nguồn.

Thêm link store

Bước 1/2 · Nhập danh sách

Mỗi dòng là một app. Trên một dòng có thể có link Google Play, link App Store hoặc cả hai (cách nhau bằng dấu cách, tab hoặc dấu |). Copy 2 cột từ Excel/Sheets cũng dán được. Tham số tracking trong link sẽ tự bị bỏ.

Kiểm tra tên và icon lấy về. Sửa tên nếu cần. Bấm “Sửa” để đổi hoặc thêm link (Google Play được ưu tiên lấy trước, App Store là dự phòng), rồi “Lấy lại” để cập nhật tên và icon. Xoá dòng không muốn thêm, sau đó bấm “Xác nhận”.
